# BankingBackendApps

A Banking Administration Backend Application built with Java and Spring Boot.

## About The Project

BankingBackendApps is a backend application developed as a personal learning project to explore backend development using the Spring Boot ecosystem.

This project originally started as a simple Java application without Spring Boot. As the project evolved, it was gradually migrated and refactored to adopt Spring Boot and its ecosystem to improve code organization, maintainability, and scalability.

The main goal of this project is to build a structured banking backend system while learning and implementing industry-standard backend development practices.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT Authentication
- Redis
- Maven

## Features

- Employee Management
- Customer Management
- Employee Authentication and Authorization
- JWT-based Authentication
- Redis-based Session Management
- Database Integration using Spring Data JPA

## Project Goals

This project is continuously developed with a focus on:

- Clean and maintainable code structure.
- Separation of concerns between application layers.
- Repository and service layer design.
